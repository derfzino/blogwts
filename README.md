Мой проект на практику WTS

1.Бизнес-логика работы со статьями вынесена из контроллеров в `PostService`.

2.Форматирование JSON-ответов делегировано классам `PostResource` и `UserResource`.

3.Регистрация пользователя обернута в `DB::transaction()`. Создание пользователя и генерация токена происходят как единая операция, что исключает появление «сиротских» записей при сбоях.

4.Хэширование пароля реализовано через `'password' => 'hashed'` в модели `User`. Использование `Hash::make()` в контроллерах удалено.

5.Валидация входных данных находится в Form Requests (`StorePostRequest`, `UpdatePostRequest`), а проверка прав доступа — в сервисном слое (`PostService`).

6,Все API-эндпоинты имеют алиасы.

7.Проверка авторства статьи (`user_id`) выполняется в методах сервиса.

8.Публичные эндпоинты (`GET /posts`) фильтруют только опубликованный контент. Приватные черновики доступны только автору.

9.Добавлена фильтрация и сортировка.

10.Просмотр личных блогов с возможностью последующей фильтрации
